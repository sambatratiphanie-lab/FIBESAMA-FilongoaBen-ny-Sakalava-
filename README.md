# FIBESAMA-FilongoaBen-ny-Sakalava-
Ny “FIBESAMA”na filongoaBen’ny Sakalava eto Madagasikara dia fikambanana ara-poko sy ara-tsosialy izay manana ny foibe Nasionaly (siège national)  ao Mahajanga. Mijoro ho fampiraisana, fiarovana sy fanandratana ny maha Sakalava, ny soatoavina, ny kolontsaina , ny fomba amam-panao ary ny firaisan-kina eo amin’ireo sakalava manerana an’i Madagasikara
